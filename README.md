# Mockoto

Mockoto is a private local-first platform for building, simulating, and managing APIs through collections, rules, responses, proxying, and AI-powered automation.

Designed for developers and AI agents alike, Mockoto enables rapid prototyping, testing, experimentation, and workflow execution without relying on external infrastructure.

---

## Installation

Mockoto is distributed exclusively through GitHub Packages. Access requires authorization.

**Step 1 — Authenticate with GitHub Packages:**

```bash
npm login --scope=@mockoto --registry=https://npm.pkg.github.com
```

**Step 2 — Install the CLI:**

```bash
npm install -g @mockoto/cli
```

**Step 3 — Run:**

```bash
mockoto
```

Mockoto starts a local server on `http://localhost:3000` and opens it in your browser.
